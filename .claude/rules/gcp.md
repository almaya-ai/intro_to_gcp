# Google Cloud

- תמיד מעבירים `--project` במפורש. לא סומכים על הפרויקט הפעיל ב-gcloud.
- `deploy.sh` נשאר בטוח להרצה חוזרת. כל שינוי תשתית נכנס אליו, לא רק לשורת פקודה חד-פעמית.
- אין הרשאה ברמת הפרויקט ל-Service Account של השירות, ואין `allUsers` על ה-Bucket.
- אחרי כל שינוי פריסה או הרשאה מריצים `/live-check`.
- ניסוי בהרשאות: מדפיסים את המצב לפני, לא מסתירים שגיאות, מחזירים את המצב בסיום ובודקים שחזר.
- מבדילים בין פריסה ל-Cloud Run לבין החלפת קובץ: החלפה לא יוצרת revision, ולכן מוכיחה שהשירות קורא מה-Bucket.
- מעדכנים את `docs/runbook.md` כשנוסף משאב או פקודת תפעול.
