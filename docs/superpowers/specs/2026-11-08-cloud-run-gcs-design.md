# אפיון: דף הודעה מ-Bucket פרטי

## למה
בלי השירות הזה, עדכון של הודעה בדף דורש מפתח ו-deploy. המטרה: מי שאינו מפתח מחליף קובץ ב-Cloud Storage, והקורא רואה את התוכן החדש ברענון הבא.

## מי משתמש
| מי | מה הוא עושה | מה חשוב לו |
|---|---|---|
| קורא | פותח כתובת בדפדפן | לראות תוכן עדכני, ולהבין מה קורה כשאין תוכן |
| עורך (הנחה: לא מפתח) | מחליף קובץ ב-Console | לא לשבור דברים, ולקבל הסבר כשהקובץ לא תקין |
| מפעיל השירות | בודק שהשירות תקין | לראות הוכחה שהתוכן מגיע מה-Bucket ולא מהקוד |

## מטרות
1. `/` מציג את שם הקובץ ואת תוכן `message.txt`, ונקרא מחדש בכל טעינה.
2. ה-Bucket פרטי, והשירות קורא בזהות ייעודית עם הרשאה על ה-Bucket בלבד.
3. החלפת הקובץ מציגה תוכן חדש באותה כתובת ובאותה גרסה פרוסה.
4. כל תקלה מציגה מה קרה ומה אפשר לעשות, וניסיון חוזר מוצע רק כשיש בו טעם.
5. הדף עצמו מוכיח עדכניות: `generation` של הקובץ ושם ה-revision.
6. תמיכה ב-`txt`, `md`, `csv`, עם מבנה שמאפשר להוסיף פורמטים.

## לא במסגרת
העלאה דרך הדף, התחברות משתמשים, CI/CD, `docx` ו-`pdf`, מטמון, ותיקיות בתוך ה-Bucket.

## כישלון גם אם זה "עובד"
- תוכן ישן שנראה עדכני.
- אותה הודעה לקובץ חסר ולתקלת הרשאות, כך שהקורא מחכה לשווא.
- HTML מתוך קובץ שרץ בדפדפן.
- Bucket שנגיש ישירות מהאינטרנט.

## תרחישים
| תרחיש | תוצאה צפויה |
|---|---|
| טוענים את הדף | שם הקובץ, התוכן, `generation`, revision |
| מחליפים קובץ ומרעננים | תוכן חדש, `generation` חדש, אותו revision |
| משנים שם לקובץ ומרעננים | 404, מצב המתנה, ספירה לאחור |
| מחזירים את השם | הדף חוזר לתוכן לבד |
| מעלים תמונה בשם `.txt` | 422 "נראה שזה קובץ בינארי" |
| CSV עם שורה חסרה | 422 עם מספר השורה |
| `.pdf` | 415 עם רשימת הנתמכים |
| קובץ מעל 1MB | 413, בלי להוריד אותו |
| `?file=../x.txt` | 400, בלי לפנות ל-GCS |
| Service Account בלי הרשאה | 500, "ניסיון חוזר לא יעזור" |
| HTML או סקריפט בתוך הקובץ | מוצג כטקסט ולא רץ |

## מבנה
- `parsers.py`: bytes ← תוצאה להצגה או חריגה, בלי תלות ב-GCS.
- `main.py`: `GcsSource`, טבלת המצבים ו-Flask.
- `templates/page.html`: התצוגה והניסיון האוטומטי.
- `deploy.sh`: הקמה ופריסה שאפשר להריץ שוב.

פירוט ב-[architecture.md](../../architecture.md), ונימוקים ב-[decisions.md](../../decisions.md).

## הבחירות הטכניות
Python ו-Flask (קטן ומוכר), `gcloud run deploy --source` (לא צריך Docker מקומי), ו-`markdown-it-py` (סינון מובנה של HTML).
