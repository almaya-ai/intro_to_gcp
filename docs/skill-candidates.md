# מועמדים ל-skill

כל פעולה חוזרת נרשמת כאן כבר בפעם הראשונה. `/improve` מעדכן את הספירה בסוף כל עבודה, ו-hook בתחילת כל סשן מדווח כמה שורות מסומנות "מוכן לקידום".

## איך זה עובד

| ספירה | סטטוס | מה עושים |
|---|---|---|
| 1-2 | `מועמד` | רושמים ומעלים ספירה |
| 3 ומעלה | `מוכן לקידום` | מציעים לבנות skill |
| - | `skill` | נבנה, ומקושר לנתיב שלו |
| - | `נדחה` | כותבים למה, כדי לא לחזור לדיון |

**מה נחשב:** אותה פעולה עם אותו מבנה, גם אם הערכים שונים. שתי פעולות שנראות דומות אבל דורשות שיקול דעת שונה הן שתי שורות.

**לפני קידום:** בודקים אם skill קיים או סקריפט פשוט עונים על הצורך. skill שווה בנייה כשיש בו שיקול דעת או רצף שקל לטעות בו.
